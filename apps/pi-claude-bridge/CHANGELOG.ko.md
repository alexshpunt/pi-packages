## 0.13.0 — 2026-10-21

### 달라진 것

- 브리지가 Claude Code 2.1.304(Agent SDK `^0.3.304`)를 사용합니다.
- 디버깅이 꺼져 있으면 도구 결과를 디버그 미리보기용으로 직렬화하지 않습니다.
- 진단·CC CLI 로그 경로와 수동 정리 방법을 안내합니다. 로그를 자동으로 순환하거나 삭제하지는 않습니다.

### 해결된 것

- Pi 1.3.0에서 Haiku 5.5에 추론 끄기를 표시하지 않습니다. Claude Code가 이 모델의 추론을 유지하므로 끄기를 골라도 적용되지 않았습니다.
- 객체가 아닌 설정 파일은 시작을 막거나 원본을 덮어쓰지 않고 무시합니다.
- 진단 로그 쓰기 실패가 provider 요청을 중단하거나 원래 오류를 가리지 않도록 합니다.
- Claude Code가 비스트리밍 답변을 최종 결과에서 반복해도 본문을 한 번만 표시합니다.
- 격리 요약의 토큰 사용량을 반환하며, 이미 취소된 요청을 시작하지 않고 진행 중 취소도 다른 오류와 구분합니다.
- 종료 후 마지막 쿼리나 세션이 늦게 끝나더라도 공유 훅을 해제합니다.
- 수동 로그 정리 명령이 `~`로 시작하는 agent 디렉터리 설정도 홈 경로로 해석하도록 고칩니다.
- 시작 안내나 감지한 요금제를 기록할 때 전역 설정 파일을 한 번에 교체합니다. 동시에 시작한 Pi 프로세스나 하위 에이전트가 쓰는 도중의 파일을 읽고 사용자 설정 없이 실행되는 일이 없어집니다. 심볼릭 링크로 연결한 설정 파일은 링크로 유지합니다.
