# 변경 이력

## [Unreleased]

### 새로워진 것

- `image_gen` 호출이 모델용 경로 안내 대신 작업 종류, 이미지 크기, 저장 경로를 간단히 보여 줍니다. 경로를 클릭하면 기본 앱으로 이미지를 엽니다.
- 생성된 이미지를 클릭하면 터미널 높이에 맞게 확대되고, 다시 클릭하면 원래 크기로 돌아갑니다. Pi 기본 fullscreen 모드에서 이미지마다 따로 확대됩니다.

### 달라진 것

- 번들 `imagegen` 스킬이 서로 독립적인 이미지는 한 응답에서 함께 요청해 병렬로 생성할 수 있다고 모델에게 안내합니다.
