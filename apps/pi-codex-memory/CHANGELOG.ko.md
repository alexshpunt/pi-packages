# 변경 이력

## [Unreleased]

### 새로워진 것

- Pi 대화에서 결정과 맥락을 기억으로 추출·통합하고, 다음 세션에서 출처를 인용해 꺼내 씁니다. 모드는 `/codex-memory`, 저장된 기억은 `/codex-memory-manage`, 설정은 `/codex-memory-settings`에서 다룹니다.
- 모델을 고르고 마스킹한 대화 사본의 전송을 허용해야 기억을 만듭니다.
- 모델 호출 없이 기억을 고치거나 잊을 수 있고, 잊은 대화에서는 기억을 다시 만들지 않습니다. 에이전트에게 기억해 달라고 요청하면 확인을 받은 뒤 그 내용을 저장합니다.
- 같은 Git 저장소의 하위 폴더와 worktree가 기억을 공유합니다. 다른 저장소의 기억은 요청마다 확인하거나 한 방향 접근을 저장해 읽고, 저장소 공유 이전에 폴더별로 저장한 기억은 가져올 수 있습니다.
- 대화를 압축해도 원래 사용자 발언을 추출 입력으로 씁니다.
- `@buyong/pi-codex` 번들에 포함됩니다.
