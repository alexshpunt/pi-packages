# 변경 이력

## [Unreleased]

### 새로워진 것

- Git common directory 기준으로 같은 저장소의 worktree·하위 폴더 기억을 공유하며, 기존 cwd 기억은 선택·확인한 항목만 가져옵니다.
- 요청 단위 확인 또는 단방향 읽기 연결로 다른 저장소의 기억을 조회하고, 출처가 구분되는 경로·인용과 원본 범위의 사용량을 유지합니다. 자동 주입·복사·쓰기 권한은 확장하지 않습니다.

- Codex memory v2 추출·증분 통합·범위별 조회와 `/codex-memory` 관리를 제공합니다. 생성에는 모델과 전송 설정의 명시적 선택이 필요합니다.
- SQLite 작업 소유권, 취소, 예산, 정정, 잊기, 보존과 확인된 노트를 지원하며 Codex 번들에도 포함합니다.
- 사용자 근거 우선 입력, 크기 제한 요약, 출처에 근거한 참조·식별자 검사와 주입·조회·검증 인용의 구분 표시를 제공합니다.
- 압축 뒤 재추출에서도 활성 분기의 원래 근거와 문맥 편집을 보존하며, 압축만으로 지문이 바뀌거나 기억에서 유래한 응답이 다시 근거가 되는 것을 막습니다.
