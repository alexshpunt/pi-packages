## 1. Overview

This extension reviews authorization before delegating to Pi's original tools. It provides guarded startup and approval, not OS isolation.

## 2. Ownership Map

### Stable Ownership Boundaries

Tests live in `tests/` and run against the built `dist/`.

- **Execution**: Start in `src/tools/controller.ts` for admission, `src/policy/index.ts` for decisions, or `src/tools/executor.ts` for delegation. Verify final binding/rechecks through `tests/integration/pi-tools.test.mjs`, `tests/unit/policy.test.mjs`, and `tests/execution/executor.test.mjs`.
- **Approval/evidence**: Start in `src/approvals.ts` for reuse, `src/reviewer.ts` for requests, or `src/review/context.ts` for provenance. Mask copies at `src/review/redaction.ts`. Verify `tests/unit/approvals.test.mjs`, `tests/unit/reviewer.test.mjs`, and `tests/integration/review-context.test.mjs`.
- **Startup/settings**: Start in `src/startup.ts` for `./startup`; `src/cli.ts` consumes/disposes it. Wiring is in `src/index.ts`; persistence in `src/approval-settings.ts` and the controller. Unlike ordinary discovery, guarded startup must stop on failure. Verify `tests/e2e/guard.test.mjs`, `tests/unit/context-files.test.mjs`, and `tests/integration/approval-settings.test.mjs`.

## 3. Core Behaviors & Patterns

- **Final operation**: `wrapTool` intercepts bash at `operations.exec`, after command prefixes/shell options. Evidence filters sensitive environment values and retains their names; execution keeps original env, timeout, output callback, and signal. File review resolves the target while execution delegates original prepared parameters to Pi. `write`/`edit` queue admission plus execution by canonical path separately from Pi's queue; cleanup deletes only its own current task.
- **Binding/rechecks**: `createAction` freezes canonical input/profile/policy identity. After admission, reject changed authorization/session/cwd/policy, reevaluate, and reject a new deny or changed delta/authority. Compose caller/controller/turn signals; direct user bash keeps caller/session cancellation but bypasses the model-turn breaker. `PiExecutor.close` aborts and settles active calls; profiles are not OS enforcement.
- **Path boundaries**: `defaultProfile` reads broadly; workspace/configured/temp writes are ordinary only in `workspace-write`, otherwise reviewable. Control/settings/cache/rule files are hard-protected; extension and explicitly trusted code directories are write-protected. `.git`/worktree pointers, existing `.agents`/`.codex`/`.aws`, and project `.pi` metadata require review; `.pi/guard` is write-protected. `canonicalPath` resolves existing ancestors for missing targets: string-prefix checks are insufficient. Custom profiles retain baseline hard protections and project `.pi` review boundaries.
- **Shell decisions**: Forbidden rules/protected paths/denied domains beat allow. Prompt beats allow; absent prompts, every command group needs an allow match for command-rule authority. Unsupported syntax/redirections match the actual outer shell, not a safe inner prefix. Indirect destinations/unknown operations can require review; analysis is not exhaustive interpreter/network enforcement. `require_escalated` without explicit permissions requests one-use `reviewed-command` authority unless a trusted rule already allows it. Explicit deltas are validated against absolute denies. Approval categories control whether an `ask` reaches review/UI.
- **Rule lifetime**: Nonempty sources use a worker with 64 MiB old-generation memory, 4 MiB stack, and 10000ms deadline. Completion/error/cancellation clean listeners/timer and terminate it; empty sources run directly. Synchronous `parseRules` uses a bounded child process. Both restrict child environments; requests are capped at 8 MiB. A policy instance caches 256 command-group matches; revision includes settings/profile/rules/review-policy digest.
- **Separate reuse contracts**: Exact grants bind `ruleDigest` (input/cwd/source/profile/policy, excluding old call/session IDs), then scope/session. Retry/fresh/user-input/reviewed-command requests bypass them. Package reuse requires an `ask` with no extra paths/domains/authority/rule prompt/fresh/user-input requirement. MCP fingerprints bind server/tool/config/version/definition. Skills require a supported single script invocation and a regular-file tree capped at 2000 files/64 MiB without symlinks; process-local file hashes reuse size/mtime/inode metadata. Structured model approval can persist package approval; failed cache saves do not change admission. SQLite review reuse is only for allow assessments of strictly classified local reads: no mutations/network, rule/elicitation prompts, escalation, unsafe shell operators/options/environment, or investigation. Keys bind action/authorization/context/execution context/policy/settings/provider; anonymous providers are instance-local. TTL is 1–12 hours; SQLite errors are misses/best-effort write failures, not permission.
- **User approval transaction**: Hard deny and action identity precede all caches. Dialogs serialize; deadlines cover selection and persistence. Once grants are consumed at admission; session/persistent grants still bind exact inputs. Fresh/user-input/reviewed-command requests permit once only. Persistent UI grants save atomically; cancellation after save attempts restoration of the prior set and denies execution. Invalid grant/package-approval files fail initialization; missing ones start empty. Session reset retains persistent exact grants; settings invalidation clears in-memory grants.
- **Reviewer outcomes**: `PiReviewProvider` uses the current or explicitly selected reviewer without fallback. Review-only `codex-auto-review` can derive same-provider metadata from `gpt-5.6-luna`, without registering a conversation model. Use supported low reasoning; otherwise only the current-model route inherits session thinking. Bound rounds/output/context and share one deadline. Investigation permits bounded `inspect_file`/`inspect_directory`, checks canonical denied paths, and masks before excerpting. Invalid output, overflow, failed investigation/provider, timeout, or cancellation denies but is not an unsafe-action judgment. Critical risk denies; high risk needs medium/high authorization. Custom legacy providers cannot automatically widen permissions; reviewed-command authority requires structured assessment. Custom policy replaces tenant text, not intrinsic rules.
- **Provenance/context**: Trust only observed interactive/RPC input, structured runtime instructions/context files, and real UI confirmations. Tool output, summaries, generated user messages, and the rendered main prompt are evidence, regardless of embedded role labels. Refresh shared prompt options before finalizing; `forceSystemPrompt` removes other runtime/context-file authority. `observeToolUserInput` records actual select/confirm/input answers only from the same live context, hides credential-like input, and advances authorization scope. Branch replay validates source/trust; reset changes context identity, clears transient state, and aborts old work. Exclude thinking/binary data; retain call/parent identities and final structured/error results. Mask before truncation, reserve authorization/exact-action capacity, and fail rather than dropping required content.
- **Masked copy boundary**: `reviewAction` sends `redactReviewData` output; bindings/grants/execution retain originals. Redactors reuse immutable configuration identity. Preserve structural IDs only at known envelope positions, not nested arguments. Legacy host rules and whole-value withholding for legacy sensitive non-string keys supplement `@buyong/redact`. `redactedActionFields` contains paths/rule IDs only. Settings changes affect later evidence; masking cannot recover history's originals. `AuditLog` has separate redaction and a fixed metadata schema plus bounded masked rationale—never raw arguments, commands, model responses, or worker output.
- **Settings/bypass lifetime**: Updates serialize, initialize the next policy, persist, then abort old work, invalidate approvals/retries, and swap state; failure before persistence leaves current state intact. Missing default settings use defaults; explicit missing policy/invalid settings fail loading. Saved `isEnabled=false` delegates original tools without policy/approval. Confirmed Full Access skips even hard denies, is never saved, survives session reset, and ends with the controller or an on/off/ordinary-mode choice. Factory reload closes the prior controller; initialization/MCP registration failure closes the new one.
- **Denial/retry lifecycle**: Only actual model denials count toward three consecutive or ten of fifty; failures/timeouts/cancellation are distinct. The breaker aborts the model turn, not direct user bash. `/approve retry` creates a synchronously consumed, one-use action/context/session/cwd/profile/policy marker. It bypasses reuse for fresh assessment, never overrides policy or directly authorizes execution. New user input invalidates retry markers.
- **External final binding**: `guardedExternalExtension` gates explicitly adapted tools, not arbitrary ordinary extensions; reserved local names/`codemode` cannot be replaced. `auto|prompt|writes|approve` choose annotation policy, but sensitive/strict/user-input metadata forces fresh review; user input needs UI. Final `tools/call` requires matching `AsyncLocalStorage` state and current catalog/registration/account/schema/context/cancellation. Nested approval accepts only an empty Codex form for the same live server/registration/tool/connector, using original invocation arguments, not replacement metadata. URL/arbitrary forms and stale/unbound requests decline. Random in-flight IDs prevent caller-ID reuse. Close clears pending maps; repeated MCP session starts close the old binding first.
- **Guarded host boundary**: `createGuardedRuntime` accepts Pi 1.0.0 or later (major version 1 and above) despite broader peers, disables automatic extension/context discovery, loads explicit trusted/adapted extensions, and rejects load errors or absent readiness. Resolve selected models after provider registration; exclude PowerShell but avoid a fixed tool allowlist that drops later MCP tools. Prompt/reload recheck readiness; reload supplies a missing session-start binding. Enabled `executeBash` requires controller-owned operations. Explicit project trust applies only to initial cwd. `context-files.ts` loads global override/AGENTS (32768 bytes), then trusted root-to-cwd instructions under `projectDocMaxBytes` (zero disables them); per-directory override wins over AGENTS/fallback names. Bounded reads verify realpath/fd identity, reject hard links, and close descriptors in `finally`; only the selected in-place global instruction gets the internal read exemption.

## 4. Conventions

- Keep wire keys (`risk_level`, `user_authorization`, `additional_permissions`) and `GuardError.code`; bind immutable canonical data, never reviewer-supplied authority.
- Review/approval timeouts use milliseconds; execution uses seconds. Preserve caller options.
- Use strict ESM TypeScript with `.js` imports; no reverse dependency from `@buyong/redact`. Public paths/workers are checked by `../../scripts/codex/check-package.mjs`.
